# Third-party frontend assets

The following production distributions are vendored locally so the Zendesk
theme does not depend on a runtime CDN:

- `alpine-csp.min.js`: Alpine.js CSP 3.16.3, MIT License,
  https://github.com/alpinejs/alpine
- `gsap.min.js`: GSAP 3.15.0, standard no-charge license,
  https://gsap.com/licensing/

The original distribution files are unmodified.
